This is **version 3.0.1**, a patch release of 3.0.0. With it the editor opens nothing with the system's default program: **F1** shows the user guide in a window of the program, **Copy path** takes the place of *Open* for an exported file, and **Reveal in folder** hands only a folder to the file manager. **There is no format change:** 3.0.1 writes format 3 as 3.0.0 does, and format 3 stays frozen. If you come from 3.0.0, install 3.0.1 over it; your projects need no step. If you come from 2.x, read the notes of 3.0.0 first: each project is upgraded once to format 3. If you come from 1.17.1 or older, the same upgrade takes a project through format 2 to format 3 in one step. The guide is *Upgrade a project* in the user manual (`docs/user-manual/upgrade-a-project.md`).

### From 3.0.0 to 3.0.1

- **Install over 3.0.0.** Install the `.deb` or the Windows setup program the same way as before. Unpack the `.tar.gz` into a new folder and run `./install.sh` there, or unpack the `.zip` into a new folder.
- **Update the whole team at the same time.** 3.0.0 and 3.0.1 each write their version into `project.json` and the generation record. A team that mixes them changes these files on every save.
- **Projects stay as they are.** Every written file has the same content, apart from the version stamp and the model hash that includes it. The command line and the scripting interface are unchanged.
- **Export once if you use `verify --outputs`.** It compares the files in `outputs/` with the version that runs, so outputs written by 3.0.0 fail it until you export them with 3.0.1.

### The editor opens nothing with the system's opener

- **Why.** 3.0.0 copied the links of parts and sources to the clipboard and opened no browser for them, but **F1** still handed the user guide to the system, which started a browser, and *Open* handed an exported file to the program the system uses for it. The owner decided on 2026-11-19 that both stop (decision D-250).
- **The guide in a window of the program.** **Help > User guide** (F1) shows the guide beside the editor, in a window that moves on its own; F1 again brings it to the front. Its table of contents and its links move within that window, **Back** (Alt+Left) returns and **Contents** (Alt+Home) goes to the top. A web link that leaves the guide is copied to the clipboard, and the window says so; any other link is not followed.
- **Copy path in place of Open.** In the Export window and in *Exported files*, **Copy path** (also Enter and a double-click on a file) puts the full path of the selected file on the clipboard, so that you open it where you choose. The picture of a selected drawing stays.
- **Reveal in folder shows only a folder.** *Reveal in folder*, *Reveal output folder*, *Open the folder after the export* and *Show folder* after *Export diagram* hand an existing folder on this computer to the file manager, and nothing else: not a file and not a web address.

### Known limits

- **The guide looks plainer than in a browser.** Qt's text browser shows its headings, lists, tables, code and the links of its table of contents, but not the guide's own colours, its table of contents that stays at the top or its width limit; the window gives the page the colours of the theme.
- **The limits of 3.0.0 stand.** The tool never reads a harness plan back, and an export overwrites it; the search boxes of the users' template are not written (`SEARCH` and `ISNUMBER` are planned for 3.1.0); Generate makes no splice; the row layout of a connector is not in format 3 (planned as format 4, released as 4.0.0).
- **Nobody has looked at the guide window on a real display.** It and *Copy path* were tested offscreen. Nobody has looked at the screens of 3.0.0 on a real display either, and the Windows packages were built and tested on GitHub's runners only, not on a real Windows computer. The Windows packages have no Windows code-signing certificate, so SmartScreen shows *Windows protected your PC*: **More info**, then **Run anyway**.
- **No compliance and no sign-off is claimed.** The configuration values are placeholders until your project supplies them.
