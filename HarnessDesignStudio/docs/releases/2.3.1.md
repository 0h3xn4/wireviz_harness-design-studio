This is **version 2.3.1**, a patch release of 2.3.0. It brings a new logo that stays visible in the dark mode of Ubuntu and Windows. **There is no format change:** 2.3.1 writes format 2 as 2.3.0 does, and format 2 stays frozen. The program does what 2.3.0 does; only its icon is new. If you come from 2.3.0, install 2.3.1 over it; your projects need no step. If you come from 2.2.x or older, read the notes of 2.3.0 first. If you come from 1.17.1 or older, upgrade each project once to format 2, as the notes of 2.0.0 say. The guide is *Upgrade a project to format 2* in the user manual (`docs/user-manual/upgrade-a-project.md`).

### From 2.3.0 to 2.3.1

- **Install over 2.3.0.** Install the `.deb` or the Windows setup program the same way as before. Unpack the `.tar.gz` into a new folder and run `./install.sh` there, or unpack the `.zip` into a new folder.
- **Update the whole team at the same time.** 2.3.0 and 2.3.1 each write their version into `project.json` and the generation record. A team that mixes them changes these files on every save.
- **Projects stay as they are.** Every written file has the same content, apart from the version stamp and the model hash that includes it.
- **Export once if you use `verify --outputs`.** It compares the files in `outputs/` with the version that runs, so outputs written by 2.3.0 fail it until you export them with 2.3.1.
### The new logo

- **Why.** The owner saw on 2026-11-17 that the icon of 2.3.0 was barely visible in the dark mode of Ubuntu: its purple tile has less than 2:1 contrast on a dark panel, so its edge disappears.
- **What it shows.** A device connector with pins, a bundle of three wires with a cable tie, a branch point that splits the bundle to two connectors, an amber check mark for the design-rule checks, and an orbit and a star for the spacecraft.
- **Visible on dark and light panels.** A lighter purple rim has at least 3:1 contrast on the dark and light panels of Ubuntu and Windows. The window icon, the icon of the desktop entry, the Windows icon, the logo and the banner of the documents show the same picture.

### Known limits

- **The limits of 2.3.0 stand.** Splices are not in it (planned for 3.0.0, with format 3), so a new leg takes only the free pins of a plug. Joining is in `per_connector_group` only, and the routing tree, the legs and the join are edited in the app only.
- **Nobody has looked at the new icon on a real display.** Its contrast was measured against the colours of the panels by a test, offscreen. Nobody has looked at the screens of 2.3.0 on a real display either, and the Windows packages were built and tested on GitHub's runners only, not on a real Windows computer. The Windows packages have no Windows code-signing certificate, so SmartScreen shows *Windows protected your PC*: **More info**, then **Run anyway**.
- **No compliance and no sign-off is claimed.** The configuration values are placeholders until your project supplies them.
